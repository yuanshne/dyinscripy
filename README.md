# dyinscripy

针对某主流短视频平台的个人学习用工具箱：网页界面 + 命令行，覆盖作品下载、评论导出、直播录制。

## 功能

- **用户作品下载**：输入对方主页链接或平台号，自动滚动收集全部作品，下载无水印视频（.mp4）与图集原图（.jpg），并整理元数据 CSV（标题/时间/点赞/评论/收藏/分享）
- **关键词搜索**：输入关键词自动打开搜索结果页滚动收集，结果排序可选**综合排序**或**点赞最多**（界面上两个按钮切换）。**工作方式**：搜索页大概率触发平台安全验证（点选/滑块），脚本不会也无法替你绕过——它会自动暂停等待，请直接在弹出的浏览器窗口里手动完成验证，完成后脚本检测到验证解除会自动继续收集并下载；约一半概率需要手动过一次验证，属正常现象
- **单个视频下载**：粘贴视频链接或 App 分享文案直接下载
- **评论导出**：抓取视频评论导出 CSV（昵称、内容、IP 属地、点赞数、时间）
- **批量队列**：每行一个目标，依次自动执行
- **直播录制**：录制直播**原始流**——画面里没有弹幕、评论、在线人数等网页贴片元素，原画质；支持定时开始、限定时长、未开播自动等待、断线自动重连分段续录、录完无损合成 mp4
- **网页界面**：表单 + 实时日志左右分栏，Cookie 状态徽标，系统原生文件夹选择框，配置自动记忆
- **一键登录**：弹出浏览器扫码即可，Cookie 自动保存，通常可用数周

## 快速开始

1. 安装 [Python](https://www.python.org/downloads/) 3.9+（安装时勾选 **Add to PATH**）；直播录制合成 mp4 需要系统已安装 [ffmpeg](https://ffmpeg.org/download.html)
2. 双击 **`打开爬虫界面.bat`** —— 首次运行会自动装依赖、下载浏览器内核，然后自动打开网页
3. 首次使用点「重新登录（更新 Cookie）」，在弹出的浏览器里扫码登录，Cookie 自动保存
4. 在网页里选功能、填目标、点开始，日志实时滚动显示进度

## 命令行方式

- **`开始爬取.bat`**：按提示输入目标，命令行执行作品下载
- **`开始录制直播.bat`**：按提示输入直播间链接或房间号
- 也可直接运行对应脚本查看 `--help` 参数

## 输出说明

全部输出保存在 `downloads/` 下：

| 位置 | 内容 |
|---|---|
| `平台号/videos/` | 无水印视频 .mp4（文件名：序号_发布日期_标题） |
| `平台号/images/` | 图集图片 .jpg |
| `平台号/元数据.csv` | 全部作品数据，Excel 可直接打开 |
| `comments/` | 评论 CSV |
| `live/` | 直播录制 mp4（房间号_日期_时间_partN） |

已下载的文件自动跳过：Ctrl+C 中断后重新运行即从断点继续，不会重复下载。

## 隐私与合规

- `cookies.txt` 等同于你的登录凭证，已列入 `.gitignore`，**切勿外传**
- 仅供个人学习研究使用；脚本内置随机延迟与限速，请勿改成高并发批量抓取
- 直播录制内容版权归主播所有，请勿二次传播
